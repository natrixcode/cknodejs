## 4. Підтверджені дефекти

### BUG-001 — Розрахунок вартості харчування повертає HTTP 500

**Маршрут:** `GET /api/v1/food/calculate`

Перевірені запити:

- `?age_years=2&days=1&date=2026-10-27`
- `?age_years=5&days=30&date=2026-10-27`

**Фактичний результат:** HTTP 500, `Внутрішня помилка сервера`.

**Очікуваний результат:** успішний розрахунок і відповідь API з результатом або зрозуміла помилка бізнес-логіки.

**Додаткові відомості:** у серверному журналі зафіксовано `TypeError: Cannot set property query of #<IncomingMessage> which has only a getter` у `src/routes/food_routes.js`.

**Статус:** підтверджений дефект.

### BUG-002 — Розрахунок оплати за навчання повертає HTTP 500

**Маршрут:** `GET /api/v1/tuition/calculate`

Перевірені запити:

- `?date=2026-10-27&currency=UAH&billing_period=monthly`
- `?date=2026-10-27&currency=EUR&billing_period=monthly`

**Фактичний результат:** HTTP 500 для обох запитів.

**Очікуваний результат:** коректний розрахунок для підтримуваних параметрів та контрольована помилка валідації для непідтримуваних.

**Додаткові відомості:** серверний журнал містить таку саму помилку встановлення `req.query` у `src/routes/tuition_routes.js`.

**Статус:** підтверджений дефект.

### BUG-003 — Маршрут break-even не реалізований повністю

**Маршрут:** `GET /api/v1/reports/break-even`

Запит:

`?start_date=2026-10-01&end_date=2026-10-31`

**Фактичний результат:** HTTP 501 з повідомленням про відсутні вхідні параметри прогнозу.

**Очікуваний результат:** реалізований розрахунок беззбитковості або чітко задокументований контракт необхідних параметрів.

**Статус:** функціональність недоступна; потрібне уточнення вимог і перевірка реалізації.
